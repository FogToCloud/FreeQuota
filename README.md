# FreeQuota · 穷人额度接力器

> 把各大厂白送的免费额度聚成一个入口，一家用完自动接力下一家。
> 让普通人也能免费用上原本要花钱的 AI 能力（ChatGPT / Codex / Claude 级别的体验，零月费）。

---

## 一句话讲清楚

你被豆包、ChatGPT 的「额度」坑过吗？明明昨天还能用，今天就说「限额了，明天再来」。
FreeQuota 的思路很简单：**不依赖任何一家，把智谱、硅基流动、豆包等大厂的免费额度插在同一个「排插」上**，你正常聊天，软件在后台自动挑还有额度的那一家来回答——一家用完了，无缝接力下一家，对话历史不丢。

它不是「又一个要花钱的 AI 会员」，而是**把免费额度这件事做成普通人能用的工具**。

---

## 为什么这个项目只对「白嫖党」成立（技术护城河）

大模型的「注意力缓存」是每家模型专属的。中途换模型，缓存清零，整段历史要按全价重新算一遍。
所以**付费用户中途切模型反而更贵**——这也是为什么市面上成熟的路由工具（LiteLLM、OmniRoute）都默认「一个会话锁死一个模型」。

但 FreeQuota 用的是**免费额度**：重算的成本由厂商承担，你只多等几秒。
同样的技术，付费用户算负账，免费用户算净赚。**这就是没人专门给普通人做这套东西的原因，也是本项目的空白位。**

## 功能

- **统一聊天界面**：一个网页，像用 ChatGPT 一样聊天。
- **额度接力**：当前模型额度耗尽 / 报错，自动切换下一家，上下文完整转发（你无感）。
- **额度油表**：侧边栏实时显示每家状态（正常 / 失败 / 未测试）。
- **透明可见**：每条回复标注「本次由 XX 回复」，你能看见接力在什么时候发生。
- **纯本地、零月费**：不收集任何密钥，不经手任何第三方中转，密钥只存在你自己的电脑里。

## 安装（Windows 小白友好，三步）

> 前提：电脑已装 Python 3.10+。没装的话去 python.org 下载，安装时勾选「Add to PATH」。

**第 1 步：装依赖**

在 FreeQuota 文件夹里打开命令行，运行：

```bash
pip install -r requirements.txt
```

**第 2 步：填你的免费 Key**

1. 把 `config.example.json` 复制一份，改名为 `config.json`
2. 打开 `config.json`，把里面的占位符换成你自己的免费 API Key
3. 去哪申请（都是免费，几分钟搞定）：
   - 智谱 GLM-Flash：**永久免费不限量**，注册即送，官方 bigmodel.cn
   - 硅基流动：新用户送 2000 万+ token，siliconflow.cn
   - 豆包方舟：每日 0 点刷新额度，volcengine.com（可选，按需开启）

**第 3 步：启动**

```bash
streamlit run app.py
```

浏览器会自动打开。没有就手动访问终端里提示的地址（一般是 http://localhost:8501）。

## 工作原理（给想了解的人）

```
你的提问
   │
   ▼
[接力器] 按顺序问第一家（智谱）→ 额度正常？返回答案
                    │ 失败 / 额度耗尽？
                    ▼
          把完整对话历史转发给第二家（硅基流动）
                    │ 也失败？
                    ▼
          第三家（豆包）…… 直到有人能答
```

每一家的调用都走标准的 OpenAI 兼容接口（`/v1/chat/completions`），所以只要是大厂免费的、兼容 OpenAI 格式的模型，都能接进来——**你不用懂编程，只需要在 config.json 里加一行**。

## 安全红线（本项目铁律）

1. **密钥只存在你本机的 `config.json`**，软件不收集、不上传任何密钥。请把 `config.json` 加进 `.gitignore`（本项目已默认忽略）。
2. **绝不经过第三方中转站聚合 API**。CISPA 2026 报告显示 **45.83% 的中转站存在「模型掉包」**（你以为在调 GPT，实际返回的是别的模型）。本项目只做本机直连各家官方接口。
3. **免费额度用完后可能自动从绑定的支付方式扣费**。请在各家控制台设置用量警报；本项目不做任何付费调用。

## 和市面产品的区别（为什么还要造这个轮子）

| 产品 | 问题 |
|---|---|
| OmniRoute（67K Star） | 面向程序员 + 编程工具（Claude Code / Cursor），小白用不上 |
| LiteLLM | 要 Python / Docker，给工程师 |
| Cherry Studio（42K Star） | 图形界面 + 多 Key 轮询，但**只能手动切换**，不会自动接力 |
| ClawRouter | 难度分诊很强，但**要 USDC 加密钱包**，国内基本没法用 |

**FreeQuota 的空白位：给不懂编程的中国人，一条命令启动，图形界面，面向聊天而不是写代码，且只做本机直连官方免费接口。**
